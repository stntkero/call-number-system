# 國光同濟會 捐血叫號系統

捐血者透過 LINE 官方帳號的連結查看目前叫號，工作人員用手機叫號。

| 頁面 | 網址 | 給誰用 |
|---|---|---|
| 叫號頁 | https://stntkero.github.io/call-number-system/ | 捐血者（放在 LINE 官方帳號） |
| 叫號控制台 | https://stntkero.github.io/call-number-system/admin.html | 工作人員（需密碼，**不要公開**） |

## 架構

```
捐血者手機 ──讀取──▶ Google Apps Script ◀──叫號── 工作人員手機（admin.html）
 (index.html)              │
                           ▼
                  Google 試算表「叫號系統數據」
                    工作表1!A1  目前號碼
                    工作表1!B1  公告（空白則不顯示）
                    叫號紀錄    每次叫號的時間（自動建立，用來估算等待時間）
```

- 前端：`index.html`、`admin.html`，由 GitHub Pages 提供。
- 後端：`apps-script/Code.gs`，貼在試算表的 Apps Script 裡。
- Apps Script 網址設定在 `config.js`，兩個頁面共用。

## 功能

**叫號頁（捐血者）**
- 每 5 秒自動更新，切到背景時暫停，回到畫面立即更新
- 網路不穩時保留最後的號碼，並顯示最後更新時間
- 輸入自己的號碼：顯示前面還有幾位、預估等待時間；剩 3 位內變橘色提醒，輪到時變綠色（Android 會震動）
- 顯示工作人員設定的公告（例如「休息中」）

**叫號控制台（工作人員）**
- 大按鈕「下一號」，按錯可按「上一號」
- 直接設定號碼（活動開始時設為 1）
- 設定／清除公告，有常用公告快捷鍵
- 多位工作人員同時操作也不會互相覆蓋

工作人員仍然可以直接在試算表修改 A1，效果相同，也會寫入叫號紀錄。

## 安裝／更新後端（Apps Script）

1. 開啟試算表「叫號系統數據」→ 上方選單「擴充功能」→「Apps Script」。
2. **先備份**：把編輯器裡原本的程式碼全部複製，另存到記事本。
3. 把 `apps-script/Code.gs` 的內容全部貼上，取代原本的程式碼，按「儲存」。
4. 設定密碼：左側齒輪「專案設定」→ 最下方「指令碼屬性」→「新增指令碼屬性」
   - 屬性：`ADMIN_PIN`
   - 值：叫號控制台的密碼（建議 6 位數以上，不要用生日或 123456）
5. 重新部署（**網址不會改變**）：右上角「部署」→「管理部署作業」→ 選目前的部署 → 鉛筆圖示「編輯」→ 版本選「新版本」→「部署」。
   - 確認「執行身分」是「我」，「誰可以存取」是「所有人」。
   - 如果跳出授權視窗，按「允許」。

> ⚠️ 不要按「新增部署作業」，那會產生新的網址，LINE 上的連結就要跟著換。

新版後端仍然回傳 `number`，所以換上新後端後，舊版網頁也能繼續運作。

## 活動當天流程

1. 活動前：在叫號控制台按「尚未開始」公告，並把號碼設為 0。
2. 開始叫號：清除公告，按「下一號」叫 1 號。
3. 休息時：按「休息中」，恢復時按「清除公告」。
4. 額滿時：按「今日額滿」。

預估等待時間會依當天最近幾次叫號的速度自動計算（叫滿 3 號後開始顯示），超過 20 分鐘的間隔視為休息，不列入計算。

## 注意事項

- 密碼存在 Apps Script 的指令碼屬性，**不要寫進這個存放庫**（存放庫是公開的）。
- 密碼連續輸錯 20 次，叫號控制台會暫停登入 10 分鐘；這段時間仍可直接修改試算表 A1。
- 換密碼：到「指令碼屬性」修改 `ADMIN_PIN` 即可，不需要重新部署。已登入的手機下次操作時會被要求重新登入。
