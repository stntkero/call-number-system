# 國光同濟會 捐血叫號系統

捐血者透過 LINE 官方帳號的連結查看目前叫號，工作人員用手機叫號。

| 頁面 | 網址 | 給誰用 |
|---|---|---|
| 叫號頁 | https://stntkero.github.io/call-number-system/ | 捐血者（放在 LINE 官方帳號） |
| 叫號控制台 | https://stntkero.github.io/call-number-system/admin.html | 工作人員（需密碼，**不要公開**） |

## 架構

```
捐血者手機 ──讀取──▶ Google Apps Script ◀──叫號── 工作人員手機（admin.html）
 (index.html)              │
                           ▼
                  Google 試算表「叫號系統數據」
                    工作表1!A1  目前號碼
                    工作表1!B1  公告（空白則不顯示）
                    叫號紀錄    每次叫號的時間（自動建立，用來估算等待時間）
```

- 前端：`index.html`、`admin.html`，由 GitHub Pages 提供。
- 後端：`apps-script/Code.gs`，貼在試算表的 Apps Script 裡。
- Apps Script 網址設定在 `config.js`，兩個頁面共用。

## 功能

**叫號頁（捐血者）**
- 每 20 秒自動更新；輸入號碼且前面剩 5 位內時改為每 5 秒，提醒才即時。切到背景時暫停，回到畫面立即更新
  - 號碼約 5～10 分鐘才前進一號，20 秒已足夠；這樣 150 人同時開著網頁也不會超過 Apps Script 同時執行約 30 個的上限
- 網路不穩時保留最後的號碼，並顯示最後更新時間
- 目前叫號下方顯示叫號速度（例如「目前每號約 4 分鐘」），不用輸入號碼也能自己估算等待時間
- 「快輪到我時提醒我」：輸入號碼牌上的號碼按「提醒我」，就會開啟聲音提醒，並顯示前面還有幾位、預估等待時間
- 聲音提醒：快輪到（剩 3 位，變橘色）和輪到時（變綠色）會發出提示音、整頁閃爍、震動（Android），並盡量保持螢幕常亮
  - 重新整理或重新開啟頁面後，要再按一次「開啟聲音提醒」
  - 頁面必須保持開著；iPhone 無法震動，建議關閉靜音模式
  - LINE 內建瀏覽器（特別是 Android）通常無法保持螢幕常亮；這時頁面會提示把螢幕逾時調長，或改用 Chrome／Safari 開啟
  - 這不是 LINE 推播，關掉頁面或鎖定螢幕後就不會響
- 顯示工作人員設定的公告（例如「休息中」）

**LINE 官方帳號查詢（選用）**
- 捐血者在官方帳號聊天室傳「查詢」，或直接傳自己的號碼（例如 `230`），官方帳號立即回覆目前叫號、前面還有幾位
- 使用免費的回覆訊息，**不計入每月 200 則的訊息額度**
- 其他訊息不會自動回應，工作人員仍可用聊天功能真人回覆

**叫號控制台（工作人員）**
- 大按鈕「下一號」，按錯可按「上一號」
- 直接設定號碼（活動開始時設為 1）
- 設定／清除公告，有常用公告快捷鍵
- 多位工作人員同時操作也不會互相覆蓋

工作人員仍然可以直接在試算表修改 A1，效果相同，也會寫入叫號紀錄。

## 安裝／更新後端（Apps Script）

1. 開啟試算表「叫號系統數據」→ 上方選單「擴充功能」→「Apps Script」。
2. **先備份**：把編輯器裡原本的程式碼全部複製，另存到記事本。
3. 把 `apps-script/Code.gs` 的內容全部貼上，取代原本的程式碼，按「儲存」。
4. 設定密碼：左側齒輪「專案設定」→ 最下方「指令碼屬性」→「新增指令碼屬性」（如果已經有屬性，先按「編輯指令碼屬性」再按「新增指令碼屬性」）
   - 屬性：`ADMIN_PIN`（大寫英文和底線，要一字不差）
   - 值：叫號控制台的密碼（建議 6 位數以上，不要用生日或 123456）
   - **按「儲存指令碼屬性」**，沒按儲存就離開，設定不會保留。
5. **重新授權**（新版加入了連線到 LINE 的功能，沒有授權的話整個網頁都會失效）：回到編輯器，上方函式選單選 `doGet` →「執行」→「審查權限」→ 選擇你的帳號。
   - 出現「Google 尚未驗證這個應用程式」時，按左下「進階」→「前往『專案名稱』（不安全）」→「允許」。這是自己寫的程式都會出現的提醒。
   - 下方執行記錄顯示「執行完畢」即可。
6. 重新部署（**網址不會改變**）：右上角「部署」→「管理部署作業」→ 選目前的部署 → 鉛筆圖示「編輯」→ 版本選「新版本」→「部署」。
   - 確認「執行身分」是「我」，「誰可以存取」是「所有人」。
7. **確認成功**：用瀏覽器打開 `config.js` 裡的 `API_URL`，應該看到類似 `{"number":223,...}` 的文字。如果看到「需要授權」或錯誤頁面，回到第 5 步重新授權。

> ⚠️ 不要按「新增部署作業」，那會產生新的網址，LINE 上的連結就要跟著換。

新版後端仍然回傳 `number`，所以換上新後端後，舊版網頁也能繼續運作。

## 設定 LINE 查詢功能（選用）

不設定也不影響其他功能。

1. **啟用 Messaging API**：LINE 官方帳號管理後台 → 右上「設定」→「Messaging API」→「啟用 Messaging API」。
   - 會要求選擇或建立「服務提供者（Provider）」，**建立後無法更改**，請用正式名稱，例如「國光同濟會」。
2. **取得 Channel access token**：到 [LINE Developers](https://developers.line.biz/console/) 登入 → 選剛才的 Provider → 官方帳號的 channel →「Messaging API」分頁 → 最下方「Channel access token (long-lived)」按「Issue」，複製。
3. **設定指令碼屬性**（Apps Script →「專案設定」→「指令碼屬性」→「編輯指令碼屬性」→「新增指令碼屬性」，兩個都填好後**按「儲存指令碼屬性」**）：
   - `LINE_CHANNEL_ACCESS_TOKEN`：上一步複製的 token
   - `LINE_WEBHOOK_KEY`：隨機的一組 16 字以上英數字，用來擋掉偽造的請求。**不要照抄任何範例，也不要寫進這個存放庫。**
     產生方法：在 Apps Script 編輯器新增一個暫時的函式 `function makeKey() { Logger.log(Utilities.getUuid().replace(/-/g, '')); }`，執行後複製記錄裡的那串字，再把這個函式刪掉。
4. **設定 Webhook**：回到 LINE Developers 的「Messaging API」分頁 →「Webhook URL」填入
   `Apps Script 網址?key=上一步的 LINE_WEBHOOK_KEY`（Apps Script 網址就是 `config.js` 裡的 `API_URL`）
   - 打開「Use webhook」
   - 「Webhook redelivery」保持關閉
   - 按「Verify」可能會顯示錯誤，這是 Apps Script 的已知狀況，**以第 6 步實測為準**
5. **調整回應設定**：官方帳號管理後台 →「設定」→「回應設定」
   - 「聊天」可保持開啟（工作人員可以真人回覆）
   - 「Webhook」開啟
   - 「自動回應訊息」：如果有開啟，把**沒有設定關鍵字**的回應（例如預設的「感謝您的訊息！很抱歉，本帳號無法個別回覆用戶的訊息…」）關閉或刪除，否則捐血者每傳一次號碼都會多收到這則訊息；其他關鍵字回應也避免使用「查詢」「叫號」或數字當關鍵字。不確定的話，活動期間直接把「自動回應訊息」整個關閉。
   - 建議在「加入好友的歡迎訊息」加上：「傳送您的號碼（例如 230），即可查詢目前叫號」
6. **實測**：用自己的 LINE 傳「查詢」和「230」給官方帳號，確認有收到回覆。
   - 應該只收到一則叫號回覆；如果還多收到其他訊息，回到第 5 步檢查自動回應訊息。
   - 沒收到回覆時，到 Apps Script 左側「執行作業」查看記錄（例如「LINE 查詢未設定」代表指令碼屬性沒存好）。
   - 即使本月訊息額度已用完，回覆訊息也應該可以送出（回覆不計入額度），這正好可以實際驗證。

> 換了 Channel access token 後不需要重新部署。換了 `LINE_WEBHOOK_KEY` 也不需要重新部署，但**一定要**到 LINE Developers →「Messaging API」→「Webhook URL」把 `?key=` 後面改成新的值，否則 LINE 查詢會默默失效；改完請重做第 6 步實測。改了 `Code.gs` 程式碼才需要重新部署新版本。

## 活動當天流程

1. 活動前：在叫號控制台按「尚未開始」公告，並把號碼設為 0。
   - 發號碼牌時順便告訴捐血者：「掃 LINE 官方帳號 → 點叫號網址 → 輸入號碼按「提醒我」」，或在聊天室直接傳號碼查詢。
2. 開始叫號：清除公告，按「下一號」叫 1 號。
3. 休息時：按「休息中」，恢復時按「清除公告」。
4. 額滿時：按「今日額滿」。

預估等待時間會依當天最近幾次叫號的速度自動計算（叫滿 3 號後開始顯示），超過 20 分鐘的間隔視為休息，不列入計算。

## 注意事項

- 密碼和 LINE token 都存在 Apps Script 的指令碼屬性，**不要寫進這個存放庫**（存放庫是公開的）。
- LINE 查詢功能只使用回覆訊息，不會主動推播，也不會儲存捐血者的 LINE 帳號資料。
- 密碼連續輸錯 20 次，叫號控制台會暫停登入 10 分鐘；這段時間仍可直接修改試算表 A1。
- 換密碼：到「指令碼屬性」修改 `ADMIN_PIN` 即可，不需要重新部署。已登入的手機下次操作時會被要求重新登入。
